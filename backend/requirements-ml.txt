# Target Environment: Python 3.10 on Windows / Linux with CUDA 12.4
# Core Stack: torch==2.6.0+cu124, torchvision==0.21.0+cu124, torchaudio==2.6.0+cu124
#
# REPRODUCIBLE INSTALLATION SEQUENCE:
# ------------------------------------------------------------------------------
# 1. Install core backend requirements:
#      pip install -r backend/requirements.txt
#
# 2. Install PyTorch:
#      For GPU (CUDA 12.4):
#        pip install torch==2.6.0+cu124 torchvision==0.21.0+cu124 torchaudio==2.6.0+cu124 --extra-index-url https://download.pytorch.org/whl/cu124
#      For CPU-only (e.g. CI / non-GPU hosts):
#        pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cpu
#
# 3. Install ML pinned supporting dependencies (BEFORE MeloTTS/OpenVoice):
#      pip install -r backend/requirements-ml.txt
#    Note: Pinned packages must be installed first to guarantee modern, compatible
#    versions (e.g. transformers 4.40.2, numpy 2.2.6, librosa 0.10.2, faiss-cpu 1.10.0).
#
# 4. Install OpenVoice and MeloTTS with --no-deps (MANDATORY):
#    Upstream setup.py manifests contain obsolete pins (numpy==1.22.0, librosa==0.9.1)
#    that downgrade core packages and break PyTorch 2.6. You MUST use --no-deps:
#      pip install --no-deps git+https://github.com/myshell-ai/MeloTTS.git@209145371cff8fc3bd60d7be902ea69cbdb7965a
#      pip install --no-deps git+https://github.com/myshell-ai/OpenVoice.git@74a1d147b17a8c3092dd5430504bd83ef6c7eb23
#    (Or zip archives if git CLI is absent):
#      pip install --no-deps https://github.com/myshell-ai/MeloTTS/archive/refs/heads/main.zip
#      pip install --no-deps https://github.com/myshell-ai/OpenVoice/archive/refs/heads/main.zip
#
# 5. Apply MeloTTS English-only site-packages patch:
#      python backend/scripts/patch_melo.py
#    Verify patch status:
#      python backend/scripts/patch_melo.py --verify-only
#
# 6. Pre-download required NLTK taggers:
#      python -c "import nltk; nltk.download('averaged_perceptron_tagger_eng'); nltk.download('cmudict')"
# ==============================================================================
