## What didn’t work

- **Mixed precision** on a 6 GB laptop GPU: slower and hungrier, so removed.
- **Higher expressiveness (≥ 0.65)**: higher similarity on paper, unusable babbling in practice.
- **Free hosting**: no free tier can run GPU inference; see [why it isn’t online 24/7](../../engineering/hosting/).

## What’s next

- A cleaner, longer reference recording: the largest remaining quality lever.
- Reading the real client IP from the tunnel header so per-visitor limits work when shared.
- Exploring a 2.5D cartoon video pipeline that reuses these narrations for short-form video.
