## Requirements

| | Minimum | Tested on |
|---|---|---|
| GPU | NVIDIA, 6 GB VRAM (CUDA) | RTX 3050 Laptop 6 GB |
| RAM | 8 GB | 16 GB |
| Disk | ~10 GB (environment + model weights) | |
| Software | Python 3.10, FFmpeg on PATH, Node.js 22+ | Windows 11 |

<Aside>
	A CPU-only machine can run it, but expect several minutes per chunk.
</Aside>

## Setup

<Steps>

1. **Clone the repository**

   ```bash
   git clone https://github.com/Aayush-Dubey123/audiopipeline.git
   cd audiopipeline
   ```

2. **Create the Python environment** (one environment, inside `backend/`)

   <Tabs syncKey="os">
   	<TabItem label="Windows">
   	```powershell
   	python -m venv backend\.venv
   	backend\.venv\Scripts\Activate.ps1
   	```
   	</TabItem>
   	<TabItem label="Linux / macOS">
   	```bash
   	python -m venv backend/.venv
   	source backend/.venv/bin/activate
   	```
   	</TabItem>
   </Tabs>

3. **Install PyTorch with CUDA, then the project**

   ```bash
   pip install torch==2.6.0+cu124 torchaudio==2.6.0+cu124 --extra-index-url https://download.pytorch.org/whl/cu124
   pip install -r requirements.txt
   ```

4. **Configure** by copying `backend/.env.example` to `backend/.env`. The defaults work; the voice-tuning settings are explained in [Tuning by measurement](../../engineering/tuning/).

5. **Start everything**

   ```powershell
   .\run.ps1
   ```

   This opens the backend on `http://127.0.0.1:8000` (API docs at `/docs`) and the studio on `http://localhost:3000`. The first generation downloads the model weights (a few GB) from Hugging Face.

</Steps>

## Run the tests

```bash
backend\.venv\Scripts\python.exe -m pytest backend/tests -q
```

The suite uses a throwaway database and storage folder, so it leaves nothing behind.

## Tune the voice

All three settings live in `backend/.env`:

```ini
CHATTERBOX_EXAGGERATION=0.5   # expressiveness; keep ≤ 0.6 to avoid babbling
CHATTERBOX_CFG_WEIGHT=0.4     # lower follows the reference's pace and accent more closely
CHATTERBOX_TEMPERATURE=0.75   # higher = more variation between chunks
```

<Aside type="tip" title="The best upgrade is free">
	Record a **15–30 second** reference in a quiet room, speaking naturally and expressively, without clipping. The pipeline picks the best 10 seconds automatically.
</Aside>
