## What I set out to build

A studio where you paste a script, give it a short recording of a voice, and get back a polished narration **in that voice**: Hindi first, English too. It had to run on the hardware I had: a gaming laptop with an **NVIDIA RTX 3050 (6 GB)**.

The engine is [Chatterbox Multilingual](https://github.com/resemble-ai/chatterbox) by Resemble AI, an open model that clones a voice from a few seconds of audio (zero-shot). Around it I built a FastAPI backend with a job queue, long-form chunking up to 30,000 characters, resumable jobs, a React studio UI and a test suite.

## It worked, about 60% of the time

The voice was recognisable. But played to anyone who knew the speaker, it gave itself away within seconds. Similarity scores looked fine; **listening didn’t.**

## The question I asked

Instead of swapping models, I asked: **what in my own pipeline makes the output recognisably synthetic?** That meant reading the model’s source code, measuring the reference audio, and testing every stage between “text in” and “MP3 out”.

<Aside type="tip" title="The surprising answer">
	Most of the “AI sound” didn’t come from the model. It came from **how the reference was prepared, how settings were chosen, and how chunks were stitched together**, all fixable with small, targeted changes.
</Aside>
